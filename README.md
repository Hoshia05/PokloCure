## 주요 구현

### 데이터 주도 아이템/무기 구조

원작 뱀서라이크 장르는 무기와 아이템 종류가 많을수록 재미가 커지는 반면, 1인 개발에서는
콘텐츠를 늘릴 때마다 코드를 고쳐야 한다는 점이 병목이 됩니다.
이를 **ScriptableObject 기반 3계층 구조**로 분리해 해결했습니다.

- `ItemSO` — 수치와 설정을 담는 데이터 계층 (ScriptableObject)
- `ItemController` — 레벨업·스탯 적용 등 상태를 관리하는 제어 계층
- `ItemBehaviour` — 실제 투사체·효과 동작을 수행하는 실행 계층

세 계층을 분리한 결과 **새 무기를 추가할 때 코드 수정 없이 데이터 에셋만 추가**하면 되는
구조가 되었고, 밸런스 조정도 인스펙터에서 즉시 반복할 수 있게 되었습니다.

### 오브젝트 풀링을 통한 WebGL 성능 최적화

뱀서라이크 특성상 화면에 적·투사체·피격 이펙트·데미지 숫자가 동시에 수백 개까지 생성됩니다.
브라우저 빌드는 메모리와 GC 여유가 적어 매 프레임 `Instantiate`/`Destroy`를 반복하면
프레임 드랍이 그대로 드러납니다.

적, 아이템, 피격 이펙트, UI 데미지 숫자까지 **모두 오브젝트 풀로 관리**하도록 구현해
런타임 할당을 제거했고, **WebGL 빌드에서도 체감 성능 저하 없이** 동작합니다.

### 게임 흐름 관리

`GameManager` / `StageManager`를 **싱글턴**으로 두어 씬 전환, 스테이지 진행, 전역 상태를
한 곳에서 관리하도록 했습니다.

## 설계

### 비선형 경험치 곡선

레벨이 오를수록 요구 경험치가 완만하게 가속되도록 직접 설계한 공식입니다.

```
requiredEXP(lv) = (4 * (lv+1)^2.1) - (4 / (lv+1)^2.1)
```

선형 증가는 후반이 지루해지고 지수 증가는 성장이 갑자기 멈춘 느낌을 주기 때문에,
플레이 테스트를 반복하며 지수값을 조정해 초반 성장감과 후반 지속성이 모두 유지되도록 맞췄습니다.

### 가중치 기반 스폰 시스템

시간대별 난이도에 따라 적 스폰을 가중치로 제어하고, 스폰 패턴을 세 가지로 구현했습니다.

- **개별 랜덤** — 플레이어 주변에 분산 배치
- **방사형** — 플레이어를 둘러싸는 형태로 배치
- **밀집형** — 한 방향에 뭉쳐 배치, 돌파를 강요

## 개발 이력

itch.io에 배포한 뒤 트위터와 커뮤니티에서 받은 피드백을 반영해 패치를 이어갔습니다.
플레이어 의견을 받아 항복(포기) 버튼을 추가하는 등, 실제 사용자 피드백 기반의
유지보수 사이클을 경험한 프로젝트입니다.
전체 패치 내역은 [itch.io devlog](https://hoshia05.itch.io/hoshiacure)에서 확인할 수 있습니다.
